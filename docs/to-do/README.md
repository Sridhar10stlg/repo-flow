# docs/to-do

Repo Flow tasks for this repository. Each task is one Markdown file named `<id>-<slug>.md`. Subfolders can be used as lists. This README is not a task.

Quick reference (Claude Code, with the Repo Flow skill installed):

- `/repo-flow new <title>`: create a task
- `/repo-flow start <id or title words>`: start or continue a task
- `/repo-flow pause`: before a break
- `/repo-flow done`: finish and archive to `docs/completed/`

See the [user guide](../USER_GUIDE.md) for details, including how to change the steps (the flow).
